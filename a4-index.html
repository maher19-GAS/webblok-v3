Slide API Reference
SlideEngine · Loader · SlideUtils
SlideEngine
INIT SlideEngine.init(options)
Initialize the slide engine with volume and language options.
Parameters:
totalSlides number Default 150. Total slides in the session.
startIndex number First slide to display (default 1).
lang string 'en' | 'ar' | 'fr'
transitionMs number Slide transition duration in ms (default 380).
METHOD goTo(n)
Navigate to slide number n. Clamps to valid range.
METHOD next() / prev()
Move forward or backward one slide.
METHOD first() / last()
Jump to first or last slide.
METHOD setLang(lang)
Switch display language. Accepts 'en', 'ar', 'fr'. Reloads current slide data.
METHOD getVolume()
Returns current volume number (1, 2 or 3) based on active slide.
METHOD goToVolume(v)
Jump to the first slide of volume v (1 → 1, 2 → 51, 3 → 101).
METHOD startAutoPlay(ms)
Auto-advance slides every ms milliseconds.
METHOD stopAutoPlay()
Stop auto-play timer.
METHOD getCurrent()
Returns current slide index (number).
EVENT on(event, cb)
Register an event listener. Events: init, beforeNavigate, navigate, autoplay, langChange.
// Example usage SlideEngine.init({ totalSlides: 150, startIndex: 1, lang: 'en', transitionMs: 380 }); SlideEngine.on('navigate', ({ index }) => { console.log('Now on slide', index); }); SlideEngine.setLang('ar');
Loader (window.Loader)
ASYNC loadLangVol(lang, vol)
Loads the JSON data file for language lang and volume vol. Maps Vol 1 → en/ar/fr.json, Vol 2 → en2/ar2/fr2.json, Vol 3 → en3/ar3/fr3.json.
ASYNC getSlideData(slideNum, lang)
Auto-selects the correct volume JSON and returns the slide object matching slideNum. Returns null if not found.
FN switchLanguage(lang)
Sets HTML lang/dir attributes, updates lang-btn states, stores in localStorage key 2030b_lang, dispatches languagechange event.
// Get slide 72 data in French const data = await Loader.getSlideData(72, 'fr'); // Switch language globally Loader.switchLanguage('ar');
SlideUtils (window.SlideUtils)
FN initSlide(num, renderFn)
Main slide initializer. Loads data, shows skeleton, calls renderFn(data, lang), animates, sets up footer nav and language-change listener.
FN buildSlideHeader(data, rightBtn?)
Returns header HTML with title, subtitle, and optional right-side button.
FN buildStatCard(label, value, icon, trend?)
Generates a statistics card with icon, label, value, and optional trend indicator.
FN buildProgressBar(label, value, fillClass?)
Builds an animated progress bar with label and percentage.
FN buildTimeline(milestones)
Renders a vertical timeline with status indicators (completed, in_progress, planned, vision).
FN buildFooterNav(activeIndex, lang)
Creates the bottom navigation bar with language-aware labels and icons.
FN buildRadialProgress(value, label, size?, radius?)
Animated SVG radial/donut progress ring.
FN buildBarChart(data, labels, color?)
Simple inline bar chart from data array.
FN buildCapabilityGrid(dimensions)
Grid of capability cards with progress bars for each dimension.
// Typical slide render function async function renderSlide1(data, lang) { return ` ${buildSlideHeader(data)} <div class="stats-grid"> ${buildStatCard('CTC', data.stats.ctc_balance, '💎')} </div> ${buildProgressBar('Enhancement', data.enhancement_level)} `; }
