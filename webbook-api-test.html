API Connection
Instructions
  1. Set the API Base URL to your server (e.g. https://2030b.com/webbook/api)
  2. Go to Auth → Register or Login — the token is saved automatically
  3. Create a book — the Book ID is saved automatically
  4. Create a chapter — the Chapter ID is saved automatically
  5. Use Auto Test Runner to run the full test suite in sequence
