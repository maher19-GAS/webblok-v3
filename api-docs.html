Introduction
Project overview, conventions, and quick-start guide
🚀 Quick Start
Open a1-index.html for Vol 1, a2-index.html for Vol 2, or a3-index.html for Vol 3. All viewers are self-contained and link to the shared css/styles.css and js/ scripts.
No Build RequiredStatic HTML
📁 Directory Structure
Root: a1/2/3-index.html, en/ar 1/2/3.json. Subdirs: slides/ (150 files), components/ (12 categories), css/, js/.
slides/components/js/css/
🌐 Language Support
Full bilingual support (EN/AR) via JSON data files. RTL layout auto-activates for Arabic. Language preference persisted via localStorage key 2030b_lang.
EnglishArabic / RTL
🧩 Component System
All components are standalone HTML files with embedded CSS and optional JS. They can be embedded via <iframe> or inlined. Props are passed via data-* attributes or JavaScript.
data-* PropsCSS Variables

Bilingual content schema for all 150 slides across 3 volumes
FileLanguageVolumeSlidesSizeTop-Level Keys
en.json🇺🇸 English11–5036 KBbrand, vol, slides[]

Each slide object in the array contains: id, key, header, subtitle, description, and type-specific data arrays (e.g., pillars[], milestones[], dimensions[], phases[], etc.). The key is a unique snake_case identifier used by slide renderers.

js/slide-engine.js · Version 3.0 · Global: window.SlideEngine
INITSlideEngine.init(options)Initialize the engine
Configures totalSlides (default 150), startIndex, baseUrl, transitionMs, lang, rtl. Binds keyboard and touch. Returns SlideEngine for chaining.
totalSlidesnumberoptionalDefault: 150. Set to 50/100/150 per volume.
startIndexnumberoptionalFirst slide number to display on init.
langstringoptional'en' or 'ar'. Sets RTL automatically.
transitionMsnumberoptionalSlide transition duration in ms. Default: 380.
